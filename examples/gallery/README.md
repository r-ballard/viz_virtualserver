# Checked-in artwork gallery

This directory contains sample outputs for visual inspection. `concentric/` has two SVG examples. `lsystem/` has four drawing SVGs, matching geometry JSON, and PNG previews. The root `plant-preview.png` was a duplicate of `lsystem/plant/preview.png` and was removed.

For reproducible inputs, use the JSON jobs under `examples/domain-jobs/`, `examples/concentric/`, and `examples/lsystems/`. Generated bundles belong in a chosen output directory and are not source inputs.
