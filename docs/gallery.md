# Checked-in artwork gallery

The `examples/gallery/` directory contains sample outputs for visual inspection. Its `concentric/` directory has two SVG examples. Its `lsystem/` directory has four drawing SVGs, matching geometry JSON, and PNG previews. The former root `plant-preview.png` was a duplicate of `lsystem/plant/preview.png` and was removed.

For reproducible inputs, use the JSON jobs under `examples/domain-jobs/`, `examples/concentric/`, and `examples/lsystems/`. Generated bundles belong in a chosen output directory and are not source inputs.
